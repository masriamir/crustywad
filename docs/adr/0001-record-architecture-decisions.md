# 0001. Record architecture decisions

- Status: accepted
- Date: 2026-06-05

## Context

This repository is starting from scratch and needs a durable place to record the non-obvious decisions behind the initial scaffold.

## Decision

Use Nygard-style ADRs under `docs/adr/` for architectural choices that should remain visible as the crate evolves.

## Consequences

Future contributors can extend the sequence with focused decision records instead of burying rationale in PR discussions.
